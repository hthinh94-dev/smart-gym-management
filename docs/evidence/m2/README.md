# Minh chứng nghiệm thu local M2

Thư mục này lưu ảnh chụp trực tiếp từ môi trường localhost Ngày 15. Ảnh không
chứa password, JWT hoặc dữ liệu sản xuất.

| File | Nội dung |
|---|---|
| `m2-profile-calculator.png` | Trạng thái Profile chưa hoàn thiện (`PROF-001`). |
| `m2-profile-form.png` | Profile Form với mục tiêu kép, Select all và dữ liệu tự nhập. |
| `m2-profile-calculator-result.png` | Profile đã lưu và kết quả BMI/BMR/TDEE/calories/macros. |
| `m2-body-progress.png` | Empty state Body Progress trước khi có dữ liệu. |
| `m2-body-progress-result.png` | Body Progress với baseline, cân nặng hiện tại và mục tiêu. |
| `m2-swagger-openapi.png` | Swagger UI của 10 operation M1–M2. |

Các ảnh được chụp ở viewport desktop `1440 x 900` trên frontend
`http://localhost:5174` và backend `http://localhost:8080`.
